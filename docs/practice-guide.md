# 実践ガイド：体→行動→意味の順に整える

最終更新：2026-11-08

## 使い方：今日の状態で、やることを選ぶ

このガイドは、[元のレポート](research-report.md)の結論「体と行動を入口にし、意味は後から更新する」を毎日の手順にしたものです。毎朝、今日の状態を3段階から選び、その段階のことだけをやります。

| 今日の状態 | 目安 | やること | やらないこと |
| --- | --- | --- | --- |
| 赤：しんどい | 起きるのがつらい。何も楽しくない。考えがまとまらない | チェックリストの★印だけ（睡眠・食事・光・数分の外出） | 考え方の見直し、反省、大きな決断 |
| 黄：疲れている | 動けるが体が重い。気分が沈みがち | チェックリストのすべて（体＋行動） | 新しい目標を立てること |
| 緑：余裕がある | 普段どおり動ける | チェックリストのすべて＋週1回の振り返り（意味の更新） | 調子がいいからと睡眠を削ること |

赤の日に考え方を変えようとしないのは、強いストレス下では解釈を担う前頭前野の働きが落ちているためです。赤の日が2週間近く続くときは、下の「受診・相談の目安」を見てください。

## 毎日のチェックリスト

★は赤の日もやることです。全部できなくても構いません。チェックの数より、★を毎日続けることを優先します。

### 朝

- [ ] ★ 毎日ほぼ同じ時刻に起きる（休日もずれは1時間以内）
- [ ] ★ 起きて1時間以内に外の光を浴びる（ベランダや窓際で数分でもよい）
- [ ] ★ 水を1杯飲み、何か食べる
- [ ] 今日の状態（赤・黄・緑）と、体の疲れを0〜10でメモする

### 日中

- [ ] ★ 5分だけ外を歩く（赤の日はここまでで十分）
- [ ] 合計20〜30分歩く。少し息が上がるくらいの速さが目安
- [ ] 気分を待たず、予定していた小さな活動を1つやる（例：洗濯、5分の片付け、メール1通の返信）
- [ ] 誰かと短くやり取りする（あいさつやメッセージ1通でもよい）

### 夜

- [ ] 「できたこと」を1行書く（小さなことほどよい）
- [ ] 寝る前に5分、ため息呼吸をする：鼻から吸い、もう一度短く吸い足して、口からゆっくり長く吐く
- [ ] ★ 布団で20分ほど眠れなければ一度出て、眠くなってから戻る（不眠の認知行動療法で使われる方法）

## 「自分はだめだ」と感じたときの手順

否定的な考えが浮かんだら、解釈と戦う前に体を確かめます。赤の日は3までで止めて構いません。

1. **気づく**：「今、脳が予測を出している」と心の中で言う。事実ではなく予測として扱う。
2. **体を確かめる（30秒）**：眠いか。お腹が空いているか。疲れているか。体調が悪いか。しばらく人と話していないか。
3. **体に先に手当てする**：当てはまったものに合わせて、水を飲む、何か食べる、5分歩く、横になる、ため息呼吸を5回する。
4. **小さな行動を1つ**：2分で終わることを1つやる。終わったら「できた」と記録する。
5. **言葉で見直す（緑の日だけ）**：「そう言える証拠と、そうでない証拠は何か」「友人が同じことを言ったら何と返すか」を考える。

これで気分が変わらなくても失敗ではありません。脳の予測は、一度の説得より「できた」体験の積み重ねで少しずつ書き換わります。

## 4週間の運動プラン

4週間かけて、週150分（早歩きなどの推奨量）まで少しずつ増やします。週の合計に届かなくても、続けることを優先します。

| 週 | 1週間の合計 | 例 | ポイント |
| --- | --- | --- | --- |
| 1週目 | 50分 | 10分の散歩×5日 | 慣らす週。息が上がらなくてよい |
| 2週目 | 75分 | 15分×5日 | 推奨量の半分。この量でも発症リスクは18%低いという関連がある |
| 3週目 | 120分 | 20分の早歩き×5日＋ヨガか筋ト20分×1回 | 少し息が上がる速さを混ぜる |
| 4週目 | 150分 | 30分×5日（うち2日はジョギングや坂道でもよい） | 推奨量。発症リスク25%低下と関連 |

- **強さの目安**：話せるが歌うのは難しいくらい。研究では、強度が高いほど効果が大きい傾向でした。
- **種類**：ウォーキング、ジョギング、ヨガ、筋トレのどれでも効果が報告されています。続けやすいものを選びます。
- **赤の日**：5分外を歩けばその日は十分です。
- **5週目以降**：4週目の量を維持します。持病がある場合や、長く運動していない場合は、始める前に医師に相談してください。

## 週1回の振り返り：体験から意味を更新する

緑の日に15分だけ、記録シートを見ながら次の質問に答えます。ここで初めて「意味づけ」を扱います。考え方を無理に前向きにするのではなく、今週の事実を証拠として使います。

1. 今週できたことを、記録から3つ書き出す。
2. 気分が比較的高かった日と低かった日で、睡眠・歩いた時間・人との接触はどう違ったか。
3. 「自分はだめだ」と感じたとき、体はどんな状態だったか（眠い、疲れている、空腹など）。
4. 今週の事実から見て、「自分はだめだ」はどのくらい当たっていたか。外れていた例はあるか。
5. 来週、1つだけ増やすことは何か（例：歩く日を1日増やす、就寝を15分早める）。

答えはこの下に日付を付けて書き足していくと、数週後に「体の状態と解釈の関係」が自分のデータとして見えてきます。

## 受診・相談の目安

このガイドは日常のセルフケア用で、治療の代わりにはなりません。次のどれかに当てはまるときは、精神科や心療内科、かかりつけ医に相談してください。

- 気分の落ち込みや興味の喪失が、ほぼ毎日2週間以上続いている（赤の日が続く）。
- 仕事や家事など、日常生活にはっきり支障が出ている。
- 眠れない、または寝すぎる状態が2週間以上続いている。
- このガイドを4週間続けても、気分がまったく改善しない。

**死にたい、消えてしまいたいという気持ちがあるときは、このガイドを中断して、すぐに誰かに相談してください。**

厚生労働省の[「まもろうよ こころ」](https://www.mhlw.go.jp/mamorouyokokoro/)で、電話やSNSの相談窓口を探せます。

治療中の方は、運動や睡眠の工夫を主治医に伝えたうえで併用してください。薬は自分の判断で減らしたりやめたりしないでください。

## 各実践の根拠

各実践がどの研究に基づくかを、根拠の強い順に並べました。詳しい解説と数字は[元のレポート](research-report.md)にあります。

| 実践 | 根拠 | 確かさ |
| --- | --- | --- |
| 起床時刻をそろえる、眠れなければ布団を出る | 不眠はうつ病リスクを約2倍にする（[Baglioni 2011](https://pubmed.ncbi.nlm.nih.gov/21300408/)）。高齢者で不眠の認知行動療法がうつ病の発症をほぼ半減（[Irwin 2022](https://pmc.ncbi.nlm.nih.gov/articles/PMC8733847/)） | 高い（無作為化比較試験） |
| 気分を待たずに小さな活動をする | 行動活性化はCBTと同等の効果（[Richards 2016](https://pmc.ncbi.nlm.nih.gov/articles/PMC5007415/)） | 高い（無作為化比較試験） |
| 週1回の振り返り | CBTの効果は6〜12か月後に薬を上回る（[Cuijpers 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC9840507/)） | 高い（メタ分析） |
| 4週間の運動プラン | 週150分相当で発症リスク25%低下、半分で18%低下（[Pearce 2022](https://pubmed.ncbi.nlm.nih.gov/35416941/)）。ウォーキング・ジョギングの効果はCBTと同水準（[Noetel 2024](https://pmc.ncbi.nlm.nih.gov/articles/PMC10870815/)） | 中〜低（研究の質にばらつき） |
| 朝の光 | 高照度の光療法が既存治療への上乗せで寛解率を上げた（[Menegaz de Almeida 2025](https://pubmed.ncbi.nlm.nih.gov/39356500/)） | 中（日光での効果は未検証） |
| 人と短く接する | 拒絶や孤立は炎症反応を高め、うつ症状につながる（[Slavich & Irwin 2014](https://pubmed.ncbi.nlm.nih.gov/24417575/)） | 理論と観察研究 |
| ため息呼吸 | 1日5分で気分が改善（[Balban 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC9873947/)、健康な学生）。呼吸法全般でうつ症状がやや改善（[Fincham 2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC9828383/)） | 低い〜予備的 |
| 解釈の前に体を確かめる | 意味は身体の予測からつくられるという理論（[Barrett 2017](https://pmc.ncbi.nlm.nih.gov/articles/PMC5390700/)） | 理論からの推論（直接の検証はない） |
| 赤の日に考え方を変えようとしない | ストレスで前頭前野の働きが急速に落ちる（[Arnsten 2009](https://pubmed.ncbi.nlm.nih.gov/19455173/)） | 基礎研究からの推論 |
