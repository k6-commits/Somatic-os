## 要点

- 意味・解釈と身体感覚は双方向に結びついている。「うつ病は遺伝子とウイルスで決まり、メンタルは関係ない」は研究から支持されない。
- 強いストレス下では、解釈を担う前頭前野の働きが落ちる。つらいときほど、考え方だけで立て直すのは難しい。
- 運動・睡眠・行動活性化など、身体と行動を入口にする方法は根拠が厚い。意味づけは、余裕ができてから体験をもとに更新する。

## 注意

このリポジトリの内容は研究の整理であり、個人への医療的助言ではありません。気分の落ち込みや興味の喪失がほぼ毎日2週間以上続くとき、日常生活に支障があるときは、医療機関に相談してください。死にたい気持ちがあるときは、すぐに誰かに相談してください。厚生労働省の[「まもろうよ こころ」](https://www.mhlw.go.jp/mamorouyokokoro/)で相談窓口を探せます。
