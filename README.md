## 要点

- 意味・解釈と身体感覚は双方向に結びついている。「うつ病は遺伝子とウイルスで決まり、メンタルは関係ない」は研究から支持されない。
- 強いストレス下では、解釈を担う前頭前野の働きが落ちる。つらいときほど、考え方だけで立て直すのは難しい。
- 運動・睡眠・行動活性化など、身体と行動を入口にする方法は根拠が厚い。意味づけは、余裕ができてから体験をもとに更新する。

## アプリ

デザインをもとにした、スマホで使える最初の版です。ブラウザで開き、ホーム画面に追加するとアプリのように使えます。

**公開URL：https://k6-commits.github.io/Somatic-os/**

- **できること**：朝のチェックイン（睡眠・気分・疲れ）、3つのモード（まもる日・ととのえる日・ひろげる日）、★とメニュー、歩いた時間、できたの記録、つらいとき、ため息呼吸、夜の画面（22時〜5時）、日曜日の2つの質問、わかったこと（14日分から）、週1のふりかえり、相談先、受診用のまとめ
- **記録の扱い**：記録はそのスマホのブラウザの中（localStorage）だけに保存します。サーバー、アカウント、分析ツール、外部フォントはありません。ブラウザのデータを消すと記録も消えるので、設定から書き出してください
- **ホーム画面への追加**：iPhoneはSafariの共有ボタン →「ホーム画面に追加」。Androidは Chrome のメニュー →「ホーム画面に追加」。追加すると通信がなくても開けます

### 手元で動かす・テストする

```bash
python3 -m http.server 8790 --directory app
```

```bash
node --test tests/unit/*.test.mjs
```

画面の自動テスト（`tests/e2e/app.e2e.mjs`）には Playwright が必要です。上のサーバーを動かした状態で実行します。

```bash
node tests/e2e/app.e2e.mjs http://127.0.0.1:8790
```

## 注意

このリポジトリの内容は研究の整理であり、個人への医療的助言ではありません。気分の落ち込みや興味の喪失がほぼ毎日2週間以上続くとき、日常生活に支障があるときは、医療機関に相談してください。死にたい気持ちがあるときは、すぐに誰かに相談してください。厚生労働省の[「まもろうよ こころ」](https://www.mhlw.go.jp/mamorouyokokoro/)で相談窓口を探せます。
